# BikerLink production Worker routing

Order is intentional. API, readiness and persistent connection routes are selected before any static page or image. There is no single page application fallback: an unknown API or URL cannot receive the homepage HTML.

| Priority | Request paths | Destination | Behavior |
| --- | --- | --- | --- |
| 1 | `/api`, `/api/*` | Railway `bikerlink-production.up.railway.app` | All methods and bodies; query strings, `Authorization`, cookies, `Origin`, request/response headers and status pass through. |
| 2 | `GET`/`HEAD /healthz` | Railway | Readiness response remains Railway-owned. `RAILWAY_ORIGIN` is a non-secret HTTPS Worker variable and is validated as a Railway service hostname before proxying. |
| 3 | `/ws/admin/notifications`, `/ws/diagnostic*` | Railway | WebSocket upgrade request passes through the Worker fetch proxy. |
| 4 | `GET /` with `expo-platform: ios` or `android` | Railway | Preserves the mobile Expo manifest handshake on the root path. |
| 5 | `GET`/`HEAD` origin-owned pages and resources: `/features`, `/motoclub`, `/about`, `/faq`, `/contact`, `/blog`, `/blog/*`, `/matching/*` (except the exact static `/matching` page), `/privacy-policy`, `/terms`, `/tos`, `/delete-account`, `/investors`, `/apple-review`, `/registrati`, `/accedi`, `/area-utente`, `/media`, `/admin/media`, `/admin/settings`, `/admin/secrets`, `/admin/diagnostics/live`, `/admin/visitatori`, `/pianifica`, `/docs`, `/docs/*`, `/llms.txt`, `/manifest`, `/roadmap.json`, `/matching-system.pdf`, `/leaflet-map.html`, `/leaflet-mini-map.html`, `/leaflet-tracking-map.html`, `/leaflet-picker-map.html`, `/leaflet-navigation-map.html`, `/leaflet-curvature-map.html`, `/leaflet-route-map.html`, `/uploads/*`, `/music/*`, and remaining `/assets/*` | Railway | `/privacy-policy` preserves the live 301 to `/privacy`. For non-API HTML navigation responses only, the Worker requests identity encoding, rewrites the Railway hostname to `PUBLIC_SITE_ORIGIN` in the HTML and any absolute Railway redirect, updates `Content-Length`, and drops stale entity validators. API JSON, cookies, media, SSE, and WebSocket responses are not rewritten. |
| 6 | Plain `GET /assets/images/*`, `/favicon.png`, `/favicon.ico` | Cloudflare R2 `bikerlink-website-assets` | Original images copied from backend commit `aedfb278f487105a10567c9efa4c090705b3d801`. Missing objects fall back to Railway. Plain R2 GETs expose R2's object ETag, which differs from Railway's weak ETag, and add the origin's `X-Content-Type-Options: nosniff` and `Referrer-Policy`. `HEAD`, Range, and conditional requests (`If-*`) use Railway so its weak ETag, Last-Modified, `206`, `304`/`412`, `Content-Range`, and `Accept-Ranges: bytes` behavior remain authoritative; the Worker restores the latter if it is absent after proxying. Favicon keeps its origin one-week cache policy; other images match the origin one-year immutable policy. |
| 7 | `/web-session.js` | Workers Static Assets | Byte-identical file from backend commit `aedfb278f487105a10567c9efa4c090705b3d801` (`server/public/web-session.js`, SHA-256 `c27cca2e4d835b83f24e9e411a0a0a1493341c59ad00353b4b3145dab455520a`). The production Railway origin currently returns 404 for this script even though its server-rendered pages reference it; publishing the unchanged static script fixes the broken MIME/404 request. All `/api/*` session calls from this script still proxy to Railway. |
| 8 | `/`, `/matching`, `/raduni`, `/community`, `/horus`, `/sos`, `/privacy`, `/ecosistema`, `/download`, `/en` and the corresponding eight English subpages | Workers Static Assets | Exact approved BikerTest pages with production SEO metadata. Static responses preserve default `X-Content-Type-Options: nosniff` and `Referrer-Policy: strict-origin-when-cross-origin`. |
| 9 | `/robots.txt`, `/sitemap.xml` | Workers Static Assets | Production SEO files for the approved pages; the same security headers apply. |
| 10 | Any other path/method | Worker 404 | There is no general origin catch-all. The source audit found no non-API write routes; all API methods remain covered by priority 1. |

The origin URL is the Railway-generated hostname, so TLS connects directly to Railway and cannot loop through the public site. The Worker sets `X-Forwarded-Host` and `X-Forwarded-Proto` from the original request. Railway's edge still generates `https://bikerlink-production.up.railway.app/...` in some origin-rendered HTML, whereas a direct request to the public hostname generates canonical URLs on `https://biker-link.net/...`. The HTML response rewrite restores the public host only in non-API HTML and absolute redirects; JSON/API bodies and session cookies pass through unchanged. The preview validation must verify canonical, Open Graph, and JSON-LD URLs and check that no Railway hostname remains in the rendered page. Existing non-apex hostnames and DNS records remain outside this Worker's route.

The Worker source is a candidate for the isolated `workers.dev` hostname first. The apex DNS CNAME and BikerTest Worker are not changed by this package.
